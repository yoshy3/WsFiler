## コマンド系

## 機能
- [x] 外部アプリからファイルのドロップでコピー
- [x] 外部アプリへのファイルドラッグ
- [x] ファイルの右クリックメニュー(空白部分を右クリックしたときはカレントディレクトリのメニューを表示)
- [x] A: ファイル属性変更のUnix系のファイルシステムへの対応
- [x] 設定ダイアログ

## UX
- [x] 右下の項目数と選択数は削除
- [x] ..を常に最上位に表示
- [x] フィルタ対象をDIRにも適用する
- [x] フィルタ対象ダイアログにシステム属性のファイルを表示するかどうかのチェックボックス追加
- [x] フィルタのデフォルトを空白(すべてのファイル)にする
- [x] フィルタのワイルドカードで\*や?を入力していない場合は、前後に*を自動で付与する
- [x] ディレクトリごとのカーソル位置を保存しておいて上位ディレクトリに戻ったときに復元する
- [x] 隠れファイルや読み取り専用ファイルは別の色で表示する
- [x] マウスのダブルクリックでenterキーと同じ動作をするようにする
- [x] 画像のプレビュー
- [x] バイナリファイルのプレビュー
- [x] プレビュー中にTABキーでテキスト/バイナリの切り替え
- [x] テキストファイルのプレビューからE(dit)キーでエディターを起動
- [x] L(og Disk)でパスを直接パスを入力できるテキストボックス追加
- [x] /: Terminal で起動するときに現在のペインをカレントディレクトリでシェルを起動する
- [x] O: Ubuntu(Gnome)の場合はFilesのプロパティを開く
