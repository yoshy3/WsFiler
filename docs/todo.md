## コマンド系
- [ ] 外部コマンド実行機能

## 機能
- [x] zipファイルの仮想ディレクトリ対応
- [ ] zip以外の各種圧縮形式の仮想ディレクトリ対応
- [ ] ファイル検索ダイアログから検索したあとにファイルリストを転送して仮想ディレクトリとして扱えるようにする

## UX
- [x] ドライブ変更ダイアログでファイルパスを入力した場合、ファイルのディレクトリを開いて該当ファイルにフォーカスするようにする。
- [x] ドライブ変更ダイアログで初期フォーカスをパス入力テキストボックスにして、ドライブ名一文字を入力した場合はそのドライブのカレントディレクトリに移動する
- [x] 何もないところを右クリックしたときに該当ディレクトリのコンテキストメニューを表示するようにする。
- [x] (バグ)　.gitignoreなどの.で始まり拡張子がないファイルで拡張子がgitignoreと表示されてしまう
