## コマンド系
- [x] X: 実行
- [x] Ctrl+C: ファイルパスをコピー
- [x] /: Terminalで開く
- [x] F: ファイル名で検索
- [x] PageUp: 上にスクロール
- [x] PageDown: 下にスクロール
- [x] Home: 一番上にスクロール
- [x] End: 一番下にスクロール
- [x] F5: 更新
- [x] 0: ディレクトリのブックマーク
- [x] H: 作業したディレクトリの履歴
- [x] O: ファイルのプロパティを表示
- [x] J: ファイル内容の比較

## 機能
- [ ] ファイルのドラッグ&ドロップ(ドロップでコピー)
- [ ] ファイルの右クリックメニュー(空白部分を右クリックしたときはカレントディレクトリのメニューを表示)
- [ ] 設定ダイアログ
